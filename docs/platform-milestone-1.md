## This milestone's implementation

`src/lib/platform/catalog.ts` accepts only a strict **public projection** and a pinned package hash, never a private import plan. It resolves exact course/chapter/lesson/block/objective/exercise/stimulus/media revisions, checks ownership, detects missing references/cycles/route collisions and returns independent public DTOs. It preserves authored lesson/block/exercise order, recursively resolves comprehension leaves, and computes Previous/Next across chapter boundaries in the current course. All output is explicitly **unpublished / learning not enabled / persistence not enabled**. `proposedHref` is route design metadata, not a working v2 learner link or activation authority. A hash or sealed manifest alone never grants learner access.

The shared transcript visibility helper reuses D1's conservative rule: conditional/reviewer-only/unused transcripts are withheld; an always-access use cannot override another conditional use. Private grading, rubrics and internal package inventories never enter the catalog DTO. The catalog does not read, copy, convert or rewrite learning history. It uses no special lesson IDs, 14-question limit, chapter count or A1-only route logic.

`TeachingBlock` renders explanations, grammar patterns/examples, vocabulary, reading passages, listening instructions, speaking prompts/checklists, writing prompts/models and delivery placeholders. Exercise controls and writing storage are injected by a future adapter; absent adapters are explicitly marked not connected. Missing/mismatched stimuli and audio fail closed. Conditional transcript text is hidden even if a caller accidentally supplies it. This is a reusable library, not another development preview or a finished player. Existing preview pages/behavior are unchanged.

`npm run platform:audit` validates the existing chain through the v2 reader/identity registry, exercises this catalog and prints a public metadata inventory: versions/hashes, levels/chapter/lesson identities, counts, audio/persistence status and pending reviews. It reads local files only and never connects to a database or changes a package. It does not trust manifest reviewer strings, auto-approve, stage, publish or activate.

The old `staging:check`/`staging:dev` entry points now fail closed with the current-plan pointer before reading configuration or contacting any project. Their former env template/report are clearly historical. The disabled earlier D4 transport is not the current deployment pathway and must not be enabled to work around this product decision.
